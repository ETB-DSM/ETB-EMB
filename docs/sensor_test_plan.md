# AI-Cane Sensor Test Plan

각 센서는 단독 테스트 후 통합한다.  
센서 테스트 결과는 문제 발생 시 원인을 추적할 수 있도록 날짜, 환경, 결과를 함께 기록한다.

## 1. TF-Luna LiDAR 테스트

### 테스트 목적

거리값이 실제 거리와 비슷하게 측정되는지 확인한다.

### 테스트 방법

| 테스트 | 조건 | 기대 결과 |
|---|---|---|
| 근거리 | 물체를 30cm 앞에 둠 | danger |
| 중거리 | 물체를 80cm 앞에 둠 | warning |
| 주의거리 | 물체를 130cm 앞에 둠 | notice |
| 안전거리 | 물체를 200cm 이상에 둠 | safe |
| 미감지 | 센서 앞 장애물 없음 | safe 또는 None |

### 확인 항목

- [ ] 거리값이 cm 단위로 반환됨
- [ ] 잘못된 값은 None 처리됨
- [ ] 5개 LiDAR가 방향별 dict로 반환됨
- [ ] 연속 측정 중 값이 비정상적으로 튀지 않음

### 기대 반환 형식

```python
{
    "front": 120,
    "left": 80,
    "right": 200,
    "upper": None,
    "lower": 60,
}
```

## 2. 진동모터 테스트

### 테스트 목적

위험 단계에 따라 진동 패턴이 구분되는지 확인한다.

| risk_level | 기대 진동 |
|---|---|
| danger | strong |
| warning | medium |
| notice | weak |
| safe | off |
| unknown | off |

### 방향별 기대 동작

| direction | 기대 모터 |
|---|---|
| left | 왼쪽 진동 |
| right | 오른쪽 진동 |
| front | 양쪽 진동 |
| upper | 양쪽 진동 |
| lower | 양쪽 진동 |

### 확인 항목

- [ ] IN 핀 HIGH에서 진동 발생
- [ ] IN 핀 LOW에서 진동 정지
- [ ] weak / medium / strong 패턴 구분 가능
- [ ] 연속 동작 시 전원 불안정 없음

## 3. 서보모터 테스트

### 테스트 목적

설정한 각도에 맞게 서보모터가 안정적으로 이동하는지 확인한다.

| 테스트 | 입력 각도 | 기대 결과 |
|---|---:|---|
| 최소 각도 | 0 | 최소 위치 이동 |
| 중앙 각도 | 90 | 중앙 위치 이동 |
| 최대 각도 | 180 | 최대 위치 이동 |
| 좌측 스캔 | 45 | 왼쪽 방향 이동 |
| 정면 스캔 | 90 | 정면 방향 이동 |
| 우측 스캔 | 135 | 오른쪽 방향 이동 |

## 4. 카메라 테스트

### 테스트 목적

USB 카메라에서 frame이 실시간으로 들어오는지 확인한다.

### 확인 항목

- [ ] `/dev/video0` 인식
- [ ] frame 반환
- [ ] 파일 저장 없이 frame 전달 가능
- [ ] YOLO/OCR에 같은 frame 전달 가능

### 기대 반환

```python
frame
```

OpenCV 기준 `frame`은 numpy array 형태의 이미지 데이터이다.

## 5. YOLO 테스트

### 테스트 목적

카메라 frame에서 객체 탐지 결과가 반환되는지 확인한다.

### 기대 반환 형식

```python
[
    {
        "label": "person",
        "confidence": 0.91,
        "box": [120, 80, 300, 420]
    }
]
```

### 확인 항목

- [ ] frame 입력을 직접 받음
- [ ] yolo.py 내부에서 카메라를 직접 열지 않음
- [ ] 객체 label, confidence, box 반환
- [ ] 탐지 실패 시 빈 list 반환

## 6. OCR 테스트

### 테스트 목적

카메라 frame에서 텍스트 인식 결과가 반환되는지 확인한다.

### 기대 반환 형식

```python
{
    "text": "학생회관",
    "confidence": 0.82
}
```

### 확인 항목

- [ ] frame 입력을 직접 받음
- [ ] ocr.py 내부에서 카메라를 직접 열지 않음
- [ ] 텍스트와 신뢰도 반환
- [ ] 인식 실패 시 빈 문자열 또는 None 처리

## 7. GPS 테스트

### 테스트 목적

현재 위치 좌표가 정상적으로 반환되는지 확인한다.

### 기대 반환 형식

```python
{
    "latitude": 37.123,
    "longitude": 127.123,
    "valid": True
}
```

### 확인 항목

- [ ] UART 포트 인식
- [ ] NMEA 데이터 수신
- [ ] 위도/경도 파싱
- [ ] GPS 신호 없음 상태 처리
